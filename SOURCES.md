## 1. Template best practices — framer.com/help/articles/template-best-practices/
Updated "2 months ago" at retrieval. Headline rules applied here:

- **Originality:** clear audience/use case; layouts/flows/visual design
  original and differentiated; existing templates not reused or lightly
  modified; meaningful value beyond native Framer features.
- **Design:** consistent styling; clear hierarchy; shared text and
  colour styles throughout; **custom 404 page included**; polished assets.
- **Layout:** clear page purpose; layout templates where appropriate;
  stacks, grids, auto-height; no horizontal scrolling.
- **Text:** legible; spelling/grammar reviewed; Framer fonts; no
  placeholder / lorem ipsum content left in.
- **Responsive:** clean adaptation across mobile, tablet, desktop;
  avoid fixed sizes that break responsiveness.
- **Links:** `mailto:` / `tel:` for contact actions; recognisable
  interactive elements; hover/active states; no broken links.
- **CMS:** repeatable content in CMS where appropriate; fields clearly
  connected; clear collection/field naming; no empty/unused entries.
- **Code:** clean, minimal custom code; native features first; embeds
  only when necessary.
- **Effects:** purposeful motion only; performance considered.
- **Assets:** clearly named folders; no duplicates; descriptive file names.
- **Tags:** semantic tags; logical heading structure; meaningful alt text.
- **Accessibility:** page title + description per page; colour contrast;
  labelled form fields.
- **Performance:** images/media optimised; no large uncompressed assets.
- **Copyright:** assets original or properly licensed.
- **Marketplace:** preview images accurate; demo video uses a custom
  cover image (not an auto frame); relevant categories; description
  explains value; setup/limitations communicated.
- **Support:** support options, refund terms clearly communicated;
  no ads/unrelated promotions.
- FAQ on that page: best practices are **not formally required**, and
  **Framer does not manually review templates** — quality is the
  creator's responsibility. (We treat the checklist as required anyway.)

## 2. How to publish a template — framer.com/help/articles/how-to-publish-a-template/
Updated "3 weeks ago" at retrieval:

- Marketplace → top-left menu → Creator → **New Template**.
- Required: name, byline, description; images, categories, styles,
  features; **Preview URL** and **Remix URL**; payment settings if paid.
- **Published immediately — no approval / review / waiting period.**
- Paid templates: **creators keep 100% of template sales.**
- Templates may also be sold outside the Framer Marketplace.
- Contact for creator questions: creators@framer.com.

## 3. How to create a remix link — framer.com/help/articles/how-to-create-a-remix-link/

- Dashboard: project card ••• → Copy Remix Link, or in-project:
  top-right menu → File → Copy Remix Link, or ⌘K → "Remix".
- Remix is disabled if the project is set to "Only team members can
  access" — fix in the invite popover before submitting.
- Opening a remix link shows project name/author/preview; Copy creates
  an exact copy in the buyer's workspace. For paid templates the buyer
  receives the remix link (typically by email) after checkout — our
  checkout is Stripe, per Cory's 2026-11-15 decision (Stripe for theme
  payments, Stripe Tax as the sales-tax/VAT mitigation).
